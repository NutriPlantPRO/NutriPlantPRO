AirCI etiquetado Sin set

Meta

Carga el set generado por prepare_label_tiles.py (carpeta completa).

Cómo

  1. Arrastra para nueva caja (copa).
  2. Clic en caja = seleccionar; Borrar o Del.
  3. Corrige ~80 buenas en total (borra basura / ajusta / añade faltantes).
  4. Exportar annotations.csv → guárdalo en la carpeta del set.

Objetivo: cajas pegadas al follaje, no a la sombra. Variedad: grandes, chicas, pegadas.
